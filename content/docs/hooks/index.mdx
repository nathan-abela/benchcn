## Sources

- [useMockDevice](/docs/hooks/use-mock-device): the simulated bench every demo runs on.
- [useWebSocketSource](/docs/hooks/use-websocket-source): a device or bridge on the network.
- [useSerialSource](/docs/hooks/use-serial-source): a board on USB, through Web Serial.
- [useRingBuffer](/docs/hooks/use-ring-buffer): high-rate samples for scopes, outside React state.

All three sources return the same snapshot: `readings`, `history`, `logs`, `actuators`, `hello`, `received`, plus `command` and `send`. They are built on `createSourceStore`, which accepts any transport that speaks the [wire protocol](/docs/wire-protocol).

## Pure logic

- [Decoders](/docs/hooks/decoders): I2C, SPI, UART and Modbus RTU, with encoders.
- `wire`: protocol types, parser and serialiser.
- `ring-buffer`: fixed-capacity typed-array buffer with time-windowed reads.
- `actuator`: the command, acknowledgement, timeout and fail-safe tracker.
- `units`: engineering notation and 1-2-5 stepping.
- `boards`: typed pinouts with sources, documented on the [pinout header](/docs/components/pinout-header) page.

Shared chrome (`instrument`) and the canvas loop (`use-canvas`) install automatically as dependencies of the components that need them.
