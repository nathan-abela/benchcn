---
title: Overview
description: Data sources and pure logic you can install on their own.
---

- `mock-device`, `wire`, `ring-buffer`: the data layer. Installed automatically as dependencies of the components.
- `use-websocket-source`, `use-serial-source`, `use-ring-buffer`: React hooks that bind a source to component state.
- `decoders`: pure I²C, SPI and UART decoders with unit tests.
- `boards`: typed pinout data with a source URL in every file.
