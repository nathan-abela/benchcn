Each decoder takes arrays of logic levels and a sample rate and returns frames with sample positions. Each has an encoder that produces the same kind of trace from a description, which is how the analyzer demo and the round-trip tests work.

## I2C

```ts
import { decodeI2c, encodeI2c, summarizeI2c } from "@/lib/decoders/i2c";

const trace = encodeI2c(
  [
    { address: 0x76, read: false, data: [0xf7] },
    { address: 0x76, read: true, data: [0xa0, 0x00], repeatedStart: true },
  ],
  { sampleRate: 1_000_000, clockHz: 100_000 },
);
const frames = decodeI2c(trace);
summarizeI2c(frames);
// W 0x76: F7
// R 0x76: A0 00
```

Frames: `start`, `repeated-start`, `address` (`value`, `read`, `ack`), `data` (`value`, `ack`), `stop`. `start` and `end` are sample indices.

## SPI

```ts
import { decodeSpi, encodeSpi, summarizeSpi } from "@/lib/decoders/spi";

const trace = encodeSpi([{ mosi: [0x9f], miso: [0x00, 0xef] }], {
  sampleRate: 10_000_000,
  mode: 0,
});
const frames = decodeSpi(trace, { mode: 0 });
summarizeSpi(frames); // MOSI 9F  MISO 00 EF
```

All four modes, both bit orders, active-low or active-high chip select, and word sizes other than 8 are supported. Without a chip-select lane the decoder runs continuously.

## UART

```ts
import { decodeUart, encodeUart, summarizeUart } from "@/lib/decoders/uart";

const trace = encodeUart([0x68, 0x69], { sampleRate: 1_000_000, baudRate: 9600 });
const frames = decodeUart(trace, { baudRate: 9600 });
summarizeUart(frames); // hi
```

5 to 8 data bits, even, odd or no parity, one or two stop bits. Framing and parity errors come back as `error` frames and decoding resynchronises on the next idle line.

## Modbus RTU

Modbus decodes the UART frames, so it works on any byte stream with sample positions.

```ts
import { decodeUart } from "@/lib/decoders/uart";
import {
  decodeModbus,
  encodeModbus,
  modbusUartOptions,
  summarizeModbus,
} from "@/lib/decoders/modbus";

const options = { baudRate: 19_200 };
const trace = encodeModbus(
  [
    { address: 1, pdu: [0x03, 0x00, 0x6b, 0x00, 0x03] },
    { address: 1, pdu: [0x03, 0x06, 0x02, 0x2b, 0x00, 0x00, 0x00, 0x64] },
  ],
  { ...options, sampleRate: 1_000_000 },
);
const chars = decodeUart(trace, modbusUartOptions(options));
summarizeModbus(decodeModbus(chars, { ...options, sampleRate: 1_000_000 }));
// addr 1  request  Read holding registers  start 107, count 3  CRC ok
// addr 1  response  Read holding registers  107: 555 0 100  CRC ok
```

Each frame carries its `address`, `functionCode`, `role` (request or response), a parsed `pdu`, the `crc` and any `errors`.
