## Usage

```tsx
import { useMockDevice } from "@/hooks/use-mock-device";
import { SerialConsole } from "@/components/ui/serial-console";
import { isCommand, parseLine } from "@/lib/wire";

export function Console() {
  const { logs, send } = useMockDevice();
  return (
    <SerialConsole
      lines={logs.map((log, i) => ({ id: i, text: log.log, level: log.lvl, t: log.t }))}
      onCommand={(line) => {
        const message = parseLine(line);
        if (message && isCommand(message)) send(message);
      }}
    />
  );
}
```

Plain text lines from the device arrive as `info` logs through the wire protocol's parser, so a firmware that only prints works unchanged.

## Examples

### Read only

Leave out `onCommand` and the input disappears.

### Warnings and errors only

```tsx
<SerialConsole lines={lines} levels={["warn", "error"]} />
```

### Echoing sent lines

Add what you send to `lines` with `direction: "out"` and it is drawn in the second channel colour with an arrow.

## Keyboard

| Key       | Result                       |
| --------- | ---------------------------- |
| Enter     | Sends the line               |
| Up / Down | Walks the last 50 sent lines |
| Escape    | Clears the input             |

## Theming

The log area uses the dark screen colour. Levels use `--muted-foreground`, `--warning` and `--destructive`, and sent lines use `--channel-2`. The frame follows your card tokens.

## Accessibility

The log is a `log` region with live announcements off, so a chatty device does not talk over the screen reader. The input is labelled. The Follow pill is a button.
