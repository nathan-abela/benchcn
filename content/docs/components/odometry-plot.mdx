## Usage

`usePoseTrail` reads `pose-x`, `pose-y` and `heading` from any source and adds a point each time the robot has moved more than a centimetre.

```tsx
import { useMockDevice } from "@/hooks/use-mock-device";
import { usePoseTrail } from "@/hooks/use-pose-trail";
import { OdometryPlot } from "@/components/ui/odometry-plot";

export function Path() {
  const source = useMockDevice();
  const { path, pose } = usePoseTrail(source);
  return <OdometryPlot path={path} pose={pose} />;
}
```

Pass `channels` to the hook if your firmware names them differently. Heading is in degrees, counterclockwise from +x.

The plot is decorative. The current x, y and heading are written as text underneath.
