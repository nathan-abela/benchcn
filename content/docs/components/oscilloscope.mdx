## Usage

The scope renders whatever samples you hand it. Pass `data` as a function and it pulls fresh samples on every frame without re-rendering React.

```tsx
import { createMockDevice } from "@/lib/mock-device";
import { Oscilloscope } from "@/components/ui/oscilloscope";

const device = createMockDevice();
const sampleRate = 1_000_000;
const n = 8192;

export function Scope() {
  return (
    <Oscilloscope
      channels={[
        {
          id: "ch1",
          data: () => device.waveform("ch1", Date.now() - (n / sampleRate) * 1000, n, sampleRate),
          sampleRate,
          voltsPerDiv: 0.5,
        },
      ]}
      timebase={0.0002}
      trigger={{ level: 0.2, edge: "rising" }}
    />
  );
}
```

With real hardware, keep a ring buffer per channel and feed it `block` messages from a source:

```tsx
import { useRingBuffer } from "@/hooks/use-ring-buffer";
import { useWebSocketSource } from "@/hooks/use-websocket-source";

const source = useWebSocketSource("ws://scope.local/ws");
const ch1 = useRingBuffer(source, "ch1", { capacity: 65_536 });

<Oscilloscope
  channels={[{ id: "ch1", data: () => ch1.tail(8192).values, sampleRate: ch1.sampleRate }]}
/>;
```

## Anatomy

```tsx
import { Scope } from "@/components/ui/oscilloscope";

<Scope.Root channels={channels} timebase={0.001} trigger={{ level: 0 }}>
  <Scope.Status />
  <Scope.Screen />
  <Scope.Readout />
  <Scope.Measurements items={["frequency", "peakToPeak"]} />
  <Scope.Cursors />
</Scope.Root>;
```

`Oscilloscope` is `Scope.Root` with the bezel, a header, the screen, the readout and the measurements. Use the parts when the scope sits inside your own panel.

## Examples

### Two channels with an offset

Logic-level signals sit on top of analog ones by giving each channel its own scale and offset, in divisions from the centre line.

```tsx
channels={[
  { id: "audio", data: audio, sampleRate, voltsPerDiv: 0.5 },
  { id: "gate", data: gate, sampleRate, voltsPerDiv: 1, offset: -2.5 },
]}
```

### Normal trigger mode

In `normal` mode the screen holds the last triggered capture instead of free running, which is what you want when hunting an intermittent pulse.

```tsx
trigger={{ source: "ch1", level: 1.2, edge: "falling", mode: "normal" }}
```

### Cursors

`cursors="time"` or `cursors="voltage"` puts two lines, A and B, on the screen and their readouts under it: both positions, the difference, and for time cursors 1/Δt as a frequency. Time is read from the trigger point and voltage from the trigger source's zero, through that channel's scale and offset. The cursors stay where you put them on the screen when the timebase or volts per division change, as they do on a bench scope.

```tsx
<Oscilloscope channels={channels} timebase={0.0002} cursors="time" />
```

### Stopped

`running={false}` freezes both the drawing loop and the measurements.

## Theming

The bezel, labels and readouts use shadcn tokens. The screen is always dark (`--scope-screen`, falling back to a warm near-black) because displays are the emissive part of a bench. Traces use `--channel-1` to `--channel-4` from `@benchcn/tokens`, then `--chart-n`, then any `color` you pass.

## Accessibility

The canvas is decorative. A visually hidden sentence next to it reads the current measurements for each channel, and the measurement cells are real text updated ten times a second.

| Interaction             | Result                                                      |
| ----------------------- | ----------------------------------------------------------- |
| Drag on the screen      | Sets the trigger level when `onTriggerLevelChange` is given |
| Drag a cursor           | Moves it                                                    |
| Arrow keys on a cursor  | Move it a tenth of a division, or a whole one with Shift    |
| Home or End on a cursor | Send it to the edge of the screen                           |

Each cursor is a focusable slider that announces its reading, for example "Cursor A, time, 400 µs".

Under `prefers-reduced-motion` persistence is disabled and the screen redraws four times a second.
