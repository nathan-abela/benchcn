Press an arrow to move the stage one step; hold it and it repeats after 400 ms. Pick 0.1, 1 or 10 mm, or focus the pad and use the arrow keys. The X and Y readouts are the positions the stage acknowledged, not the ones you asked for.

## Usage

`onJog` gets one relative move per step. Add it to the last commanded target and send the absolute position, so a fast hold never resends a position that is still waiting for its acknowledgement.

```tsx
import { useMockDevice } from "@/hooks/use-mock-device";
import { DPad } from "@/components/ui/d-pad";

export function Stage() {
  const { setpoints, command } = useMockDevice();
  const x = setpoints["jog-x"];
  const y = setpoints["jog-y"];
  const to = (axis: typeof x, delta: number) => (axis?.commanded ?? axis?.confirmed ?? 0) + delta;
  return (
    <DPad
      position={{ x: x?.confirmed, y: y?.confirmed }}
      pending={x?.pending || y?.pending}
      onJog={(move) => {
        if (move.x) command("jog-x", to(x, move.x));
        if (move.y) command("jog-y", to(y, move.y));
      }}
      onHome={() => {
        command("jog-x", 0);
        command("jog-y", 0);
      }}
    />
  );
}
```

For a G-code machine, send `G91 G0 X0.1` per move instead and read the position back from its status report.

## Keyboard

| Key        | Result                         |
| ---------- | ------------------------------ |
| Arrow keys | One step, repeating while held |
| Home       | `onHome`                       |
| Tab        | The pad, then each step size   |

The operating system's key repeat is ignored; holding uses `repeatDelay` and `repeatInterval` like the pointer. Repeating stops on release, pointer cancel, focus leaving, the window losing focus or the tab hiding.

## Accessibility

The pad is a focusable group labelled by `label` and described by its keys, so it is one tab stop. Each arrow is labelled with its axis and step, such as "X +1.0 mm", and the step sizes are toggle buttons with `aria-pressed`. The status is a polite live region.
