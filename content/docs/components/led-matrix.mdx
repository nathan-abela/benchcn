The red panel is four 8×8 modules in a row with a message longer than its 32 columns, so it scrolls. The clock fits and sits still. The heart is a single module showing a bitmap.

## Usage

```tsx
import { LedMatrix } from "@/components/ui/led-matrix";

<LedMatrix text="HELLO" color="red" />
<LedMatrix text={`TEMP ${temp.toFixed(1)}°C`} cols={64} />
```

Text that fits is centred. Text that does not fit enters from the right edge, leaves by the left and starts again. New text of a live reading carries on from the same column, so a value can change mid-scroll.

### Bitmaps

Pass a bitmap for icons and animation frames. It is drawn from the top left and clipped to the panel.

```tsx
import { createBitmap, setPixel } from "@/lib/bitmap";

const dot = createBitmap(8, 8);
setPixel(dot, 3, 3);

<LedMatrix bitmap={dot} cols={8} label="Dot" />;
```

## Examples

### Square LEDs

`shape="square"` draws the square-lens modules; `size` is the pitch of one LED in CSS pixels.

```tsx
<LedMatrix text="OK" cols={16} shape="square" size={12} />
```

### Speed

`speed` is in columns per second. `scroll={false}` clips the text at the right edge.

```tsx
<LedMatrix text="Departures 14:32 platform 4" speed={24} />
```

## Theming

`color` takes the LED presets (`red`, `amber`, `green`, `blue`, `white`) or any CSS colour, and defaults to `--primary`. The panel is dark in both themes, so theme colours take their dark-theme values. Unlit LEDs keep a trace of their colour, as they do on a real panel.

## Accessibility

The panel is decorative. A visually hidden text carries `label`, or the text itself, so a screen reader hears the whole message once and not a column at a time. Under `prefers-reduced-motion` text does not scroll and the panel shows its start.
