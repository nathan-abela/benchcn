<ComponentPreview name="robot" />

Hold Drive to enable it, then drag the joystick or use the keys: the robot moves and the odometry draws its path. Press STOP and the drive drops at once. Reset the stop and the drive stays off. Try to enable it while stopped and the device refuses. Let go of the joystick mid-drive and the robot halts. Cut the commands and its watchdog stops it too.

<InstallTabs item="robot" />

## Usage

```tsx
import { Robot } from "@/components/robot";

<Robot />;
```

With hardware, pass any source handle and the robot's top speeds:

```tsx
import { useWebSocketSource } from "@/hooks/use-websocket-source";

const source = useWebSocketSource("ws://rover.local/ws", { failSafe: { drive: false } });

<Robot source={source} limits={{ linear: 0.8, angular: 2 }} />;
```

## Props

| Prop       | Type                                                                   | Default      | Meaning                                           |
| ---------- | ---------------------------------------------------------------------- | ------------ | ------------------------------------------------- |
| `source`   | `SourceHandle`                                                         | its own mock | Readings, actuators, `command` and `send`         |
| `title`    | `string`                                                               | `"Robot"`    |                                                   |
| `layout`   | `"grid" \| "kiosk"`                                                    | `"grid"`     | Kiosk fills 800×480 with stop, joystick and drive |
| `channels` | `Partial<{ estop, drive, linear, angular, speed, turnRate, battery }>` | defaults     | Channel ids on your device                        |
| `limits`   | `{ linear?, angular? }`                                                | 0.5, 1.5     | Speeds at full stick, in m/s and rad/s            |

## Firmware

The device declares `estop` and `drive` as actuators and `linear` and `angular` as setpoints, publishes `speed`, `turn-rate`, `battery`, `pose-x`, `pose-y` and `heading`, refuses to enable the drive while the stop is engaged, and stops on its own when no velocity arrives for half a second. The joystick only streams while the device has confirmed the drive.
