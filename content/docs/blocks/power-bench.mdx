<ComponentPreview name="power-bench" />

Hold Output to switch the supply on. The load drifts between 4 and 20 ohms, so at the default 5 V and 1 A limit the supply drops into constant current every few seconds: the CC light comes on, the voltage sags, and the log says so. Raise the current limit and it stays in CV. The meter at the load reads a few millivolts under the supply, because current through the test leads drops voltage.

## Usage

```tsx
import { PowerBench } from "@/components/power-bench";

<PowerBench />;
```

With hardware, pass any source handle and the supply's limits:

```tsx
import { useSerialSource } from "@/hooks/use-serial-source";

const source = useSerialSource({ baudRate: 115200, failSafe: { "psu-out": false } });

<PowerBench source={source} limits={{ volts: 30, amps: 5 }} />;
```

## Props

| Prop       | Type                                                        | Default         | Meaning                                       |
| ---------- | ----------------------------------------------------------- | --------------- | --------------------------------------------- |
| `source`   | `SourceHandle`                                              | its own mock    | Readings, setpoints, actuators and `command`  |
| `title`    | `string`                                                    | `"Power bench"` |                                               |
| `layout`   | `"grid" \| "kiosk"`                                         | `"grid"`        | Kiosk fills 800×480 without the chart and log |
| `channels` | `Partial<{ volts, amps, output, vout, iout, mode, meter }>` | defaults        | Channel ids on your device                    |
| `limits`   | `{ volts?, amps? }`                                         | 30 V, 3 A       | Highest values the setpoint inputs will send  |

## Firmware

The device declares `psu-v` and `psu-i` as setpoints and `psu-out` as an actuator in its hello, acknowledges `set` commands with the value it applied, and publishes `psu-vout`, `psu-iout`, a `psu-mode` sample of `"CV"`, `"CC"` or `"OFF"`, and `dmm-v` if a meter is attached.
