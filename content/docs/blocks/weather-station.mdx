## Props

| Prop       | Type                                                    | Default             | Meaning                    |
| ---------- | ------------------------------------------------------- | ------------------- | -------------------------- |
| `source`   | `SourceHandle`                                          | its own mock        |                            |
| `title`    | `string`                                                | `"Weather station"` |                            |
| `layout`   | `"grid" \| "kiosk"`                                     | `"grid"`            | Kiosk fills 800×480        |
| `channels` | `Partial<{ temp, humidity, pressure, light, battery }>` | defaults            | Channel ids on your device |

## Derived values

Dew point uses the Magnus formula with the Sonntag constants (within about 0.35 °C from -45 to 60 °C). The pressure trend compares the oldest and newest values in the history; more than 0.5 hPa either way reads as rising or falling. Both are exported functions with tests.
