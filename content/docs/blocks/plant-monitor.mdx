Hold the pump. Soil moisture starts climbing once the device confirms, the LCD mirrors the state, and the console shows the acknowledgement. About one command in twenty-five is dropped by the mock device, which is when the fail-safe shows.

<InstallTabs item="plant-monitor" />

## Usage

```tsx
import { PlantMonitor } from "@/components/plant-monitor";

<PlantMonitor />;
```

With hardware, pass any source handle. The block never creates its own connection when it is given one.

```tsx
import { useWebSocketSource } from "@/hooks/use-websocket-source";

const source = useWebSocketSource("ws://plant.local/ws", { failSafe: { pump: false } });

<PlantMonitor source={source} channels={{ soil: "moisture", pump: "relay1" }} />;
```

## Props

| Prop       | Type                                             | Default           | Meaning                                             |
| ---------- | ------------------------------------------------ | ----------------- | --------------------------------------------------- |
| `source`   | `SourceHandle`                                   | its own mock      | Readings, history, actuators and `command`          |
| `title`    | `string`                                         | `"Plant monitor"` |                                                     |
| `layout`   | `"grid" \| "kiosk"`                              | `"grid"`          | Kiosk fills 800×480 with larger targets, no console |
| `channels` | `Partial<{ soil, temp, humidity, light, pump }>` | defaults          | Channel ids on your device                          |

## Kiosk mode

```tsx
<PlantMonitor layout="kiosk" />
```

Sized for the common 800×480 touchscreen: three columns, the soil tile spanning two rows, the pump control two columns wide, 48 px hold target.

## Firmware

The device needs to publish `soil`, `temp`, `humidity` and `light` samples and acknowledge `set` commands for `pump`. The [Wire protocol](/docs/wire-protocol) page shows every line to print.
